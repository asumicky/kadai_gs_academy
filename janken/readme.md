# 制作アプリのタイトル

- ゆずれない一本道

# 制作アプリの説明

- 狭い一本道で対向車とじゃんけん対決し、勝つと前進、負けると後退する、先に5勝した方が勝ちのゲームです。

# 工夫した点・こだわった点

- 息子(5歳)が最近じゃんけんが好きなのと、車と新幹線が好きなのでそこを絡めないかなと考えていました。
- SNSで偶然、狭い道で対向車とじゃんけんをして道を譲ってもらったニュースを見かけて「これだ！」と思いました。

## ギミック

- 勝敗に合わせて車が前後に動くようにし勝ち負けを視覚的にも楽しめるよう工夫しました。これは意外とすぐできず、でもこのギミックを入れたことによってイベントに関係ない指示は外に出すなど基本的なことを学べました。
- 最終結果によって相手の画像やセリフを変えキャラクターの雰囲気も楽しめるようにしました。
- playerかcomputerが5回勝ったら、じゃんけんバトルページのボタンを押したら、など表示する画面を切り替える処理をどこに入れるのか混乱しました。特に最後の5回勝ったら、のところ。

# 次回トライしたいこと（または機能）

- 効果音やアニメーションを追加して対決の臨場感を出してみたいです。
- 対戦相手や背景を増やしステージごとに違った雰囲気で遊べるようにしたいです。難易度も工夫したい。

# 備考（感想、シェアしたいこと等）

- じゃんけんの勝敗判定に加えて、得点の更新や車の移動・画面の切り替えなど、複数の動きを組み合わせることに挑戦しました。
- 考えたストーリーが実際に動くゲームになっていく過程が楽しかったです。
- 子供達に実際にプレイしてもらって、わかりづらそうなところはデザインを調整しましたが2人とも夢中になって遊んでくれたのでシンプルにとっても嬉しかったです
