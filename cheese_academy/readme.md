# 制作サイトのタイトル

- Cheese Academy TOKYO

# 制作サイトの説明

- 架空のチーズ職人養成学校「チーズアカデミーTOKYO」のランディングページ

# 工夫した点・こだわった点

- 今回いちばん大事にしたのはコードcssを学ぶことです。これまでデザインを作る側だったので、CSSでどこまで表現できるのかを確かめたくて色々チャレンジしました。
- 背景のチーズが流れる動き、チーズちゃんがマウスオーバーでブルブル震える動き、フッターの牛がふわふわ浮く動きを、すべてCSSだけで作りました。
- テーマは自由とのことだったので、チーズアカデミーをイメージしながら、デザインも自由にやってみました。クライアントワークではなかなかできない表現に挑戦したかったです。
- 「セカイを変えるチーズを作ろう」がメインコピーだったので、デザインは宇宙とチーズをイメージして作りました。
