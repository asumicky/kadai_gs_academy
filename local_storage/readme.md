# 課題提出：神経衰弱バトル × localStorage

## 1. 制作アプリのタイトル

**しんけいすいじゃくバトル（神経衰弱 × ターン制RPG × localStorage）**

## 2. 制作アプリの説明（40文字程度）

武器のカードを揃えて敵を倒すRPG風の神経衰弱。記録とステージを保存して続きから遊べます。

## 3. 工夫した点・こだわった点

前回の課題（janken2）で作った神経衰弱バトルに、localStorage を使った機能を足して進化させました。

### localStorage で保存しているもの

| キー | 中身 | 使い方 |
|---|---|---|
| `savedName` | プレイヤーの名前 | 最初の画面で入力した名前を保存し、HPバーの横に表示 |
| `stage` | 今いるステージ（1〜3） | 次に開いたときも、同じステージから再開 |
| `highScore` | クリアしたときの残りHPの最高記録 | クリア画面に表示 |
| `stats` | ゲーム回数とクリア回数（オブジェクト） | クリア画面にゲーム回数・クリア回数・勝率を表示 |

- **オブジェクトの保存**
  localStorage には文字列しか保存できないので、`stats` は `JSON.stringify` で文字列にして保存し、`JSON.parse` でオブジェクトに戻して使っています。
- **数値の取り出し**
  `stage` や `highScore` は取り出すと文字列になるので、`Number()` で数値に戻してから比べたり計算したりしています。

### ステージ制（全3ステージ）

- ステージが上がるごとに、敵のHPが +20、敵の攻撃力が +2 されます。
  - ステージ1：HP 100 / 攻撃 5
  - ステージ2：HP 120 / 攻撃 7
  - ステージ3：HP 140 / 攻撃 9
- ステージごとに、敵のキャラクターと背景の画像が変わります。
- 敵のHPバーは最大HPがステージで変わるので、`残りHP ÷ 最大HP × 100` で割合を計算しています。
- ステージ3まで勝てるように、武器のダメージを調整しました（合計 113 → 171）。
- 3ステージすべてクリアすると「全ステージクリア」画面が出て、ステージ1から遊び直せます。

### 記録の表示

- クリア画面と全ステージクリア画面に、ハイスコア・ゲーム回数・クリア回数・勝率を表示しています。
- 勝率は `クリア回数 ÷ ゲーム回数 × 100` を `Math.floor` で整数にしています。

### 名前の入力

- ページを開くと、遊び方の説明と名前の入力画面が出ます。
- 名前は localStorage に保存され、次に開いたときは入力欄に前回の名前が入った状態になります。書き換えてスタートすると、新しい名前で保存されます。
- 空欄やスペースだけの名前ではスタートできないように、`.trim()` で前後の空白を取り除いてからチェックしています。空のときは `alert()` で「名前を入力してください」と知らせます。
- 入力画面が出ている間は、カードをクリックできないようにしています。

### HPの数字表示

- HPバーの横に、敵とプレイヤーの残りHPを数字で表示しています。
- HPが変わるところ（武器・回復・HP交換・不一致のダメージ・リセット）すべてで、バーと数字を一緒に更新しています。

### データの消去

- 「データを消去」ボタンで、ステージ・ハイスコア・記録を消して最初からやり直せます。
- 間違って押しても消えないように、`confirm()` で確認を出しています（名前は消さずに残します）。

### コードの整理

- 「もう一度遊ぶ」「次のステージへ」などのボタンで同じリセット処理を使うので、`resetGame()` という関数にまとめました。

### デザイン

- カードの絵柄を絵文字から画像に変えて、スマホの画面（幅390px）に合わせたデザインにしました。
- 特殊カードの効果は「カードせつめい」の画面で確認できます。

## 4. 次回トライしたいこと（または機能）

- 敵の攻撃演出や、ダメージ数字のアニメーション
- 効果音・BGM

## 5. 備考

- 前回の課題（janken2）は11月13日時点の状態で残し、今回の課題は `local_storage` フォルダで作りました。
