# 課題提出：神経衰弱 × ターン制RPG

## 1. 制作アプリのタイトル

**神経衰弱バトル（神経衰弱 × ターン制RPG）**

## 2. 制作アプリの説明（40文字程度）

神経衰弱で武器を揃えて敵のHPを0にするRPG風ゲーム。

## 3. 工夫した点・こだわった点

- **デザインを封印して開発に振り切って時間を使ってみた！**
- **神経衰弱とRPGの組み合わせ**
  武器の絵柄を揃えると敵にダメージ、不一致だと自分がダメージを受けます。
  武器は10種類で、ダメージは絵柄ごとに変えました。
- **特殊カード5種類**
  - 💊 回復（+10）
  - 🌀 カードシャッフル（まだ伏せているカードだけをシャッフル）
  - 🛡️ 攻撃を1回回避
  - ⭐️ 3回連続で攻撃を回避
  - 👯‍♀️ 自分と敵のHPを交換
- **カードをめくるアニメーション**
  CSSの `@keyframes` で、Y軸回転して表と裏が切り替わるようにしました。
- **HPバー**
  敵（赤）とプレイヤー（青）のHPを、割合（%）でバーの幅に反映しています。
  HPがマイナスになったり、回復で100を超えたりしないように `Math.max` / `Math.min` で制限しました。
- **「もう一度遊ぶ」ボタン**
  クリア画面・ゲームオーバー画面のどちらからでも、変数・HPバー・カードをリセットして再スタートできます。
  リセット時は、カードが裏返り終わってから絵柄を入れ替えて、答えが見えないようにしました。
- **連続クリックの防止**
  判定中・ゲームオーバー中は `isChecking` / `isGameOver` で、クリックできないようにしました。
